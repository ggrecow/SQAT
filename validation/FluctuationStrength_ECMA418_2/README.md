# Fluctuation strength model according to ECMA-418-2:2025: verification of the implementation in SQAT

In SQAT, an implementation of the fluctuation strength model according to ECMA-418-2:2025 [1] (Section 9, based on the Sottek Hearing Model) is provided (see code [here](../../psychoacoustic_metrics/FluctuationStrength_ECMA418_2/FluctuationStrength_ECMA418_2.m)). The following verification studies are available for this implementation:

- [Fluctuation strength dependence of AM tones on the modulation frequency](1_AM_modulation_freq)
